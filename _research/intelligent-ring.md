I develop device-side intelligent algorithms for an intelligent ring system that jointly supports gesture interaction and user authentication for extended reality devices. The objective is to preserve recognition quality while enabling lightweight deployment on constrained hardware.

My work includes an adaptive convolutional neural network, a parameter-separation architecture combining shared experts with task-specific towers, and a Siamese network with a contrastive-learning mechanism. These components connect gesture recognition and identity verification while supporting efficient execution on the device.
